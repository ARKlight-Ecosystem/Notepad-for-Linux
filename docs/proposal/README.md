# Proposal

## Overview

Open, unsettled ideas for this project -- "should we?", not yet
"here's how." A proposal here has not been decided on; anyone can
write one, and it stays a proposal until a maintainer explicitly
accepts it.

Mirrors the role of ARKlight's `docs/Proposals/`: a **working
reference, not permanent documentation**. Unlike
[`docs/foundational/`](../foundational/README.md), a file here is
expected to eventually leave -- either promoted or dropped -- rather
than stay indefinitely.

## What happens to a proposal

- **Accepted** -- it moves to
  [`docs/implementation/`](../implementation/README.md) as a staged,
  rung-by-rung plan, and the proposal file here is retired (its
  rationale usually folds into the implementation doc or, once
  shipped, into `docs/foundational/`).
- **Rejected or abandoned** -- it's simply removed. An unsettled idea
  that didn't go anywhere isn't part of the permanent record.

## What belongs here

- A concrete "here's a change worth considering" writeup: the
  problem, the proposed approach, and the trade-offs -- for something
  that isn't decided yet.

## What doesn't

- A staged plan for something already accepted -- that's
  [`docs/implementation/`](../implementation/README.md).
- A permanent, settled design decision -- that's
  [`docs/foundational/`](../foundational/README.md).
